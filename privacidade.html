Política de Privacidade

Última atualização: 20 de maio de 2025 · Vigente a partir desta data

Resumo simples: usamos seus dados apenas para fazer o Boot Finance funcionar. Não vendemos, não repassamos e não usamos para publicidade. Seus dados financeiros são só seus.

1. Quem somos

O Boot Finance é um serviço de controle financeiro pessoal operado inteiramente via WhatsApp, desenvolvido e mantido por Guilherme Jeske ("nós", "nosso"). Para dúvidas, você pode nos contatar diretamente pelo WhatsApp no número +55 47 8472-3085.

2. Dados que coletamos

Coletamos somente o necessário para que o serviço funcione:

2.1 Dados fornecidos por você

  • Número de telefone (WhatsApp): usado como identificador único da sua conta.
  • Nome: informado no momento do cadastro, usado apenas para personalizar as mensagens.
  • Transações financeiras: valores, categorias e descrições que você registra (entradas e saídas).
  • Mensagens de texto e áudio (Plano Pro): processadas em tempo real pela IA para extração de dados financeiros. Áudios não são armazenados após o processamento.

2.2 Dados gerados automaticamente

  • Data e hora das transações: registrados automaticamente para geração de relatórios.
  • Plano contratado: Grátis ou Pro, para controle de funcionalidades disponíveis.
  • Dados de pagamento (Plano Pro): processados exclusivamente pelo Stripe. Não armazenamos dados de cartão de crédito.

3. Como usamos seus dados

Seus dados são usados exclusivamente para:

  • Registrar e categorizar suas transações financeiras.
  • Gerar relatórios mensais automáticos e exportações PDF/Excel (Plano Pro).
  • Enviar insights semanais personalizados via WhatsApp (Plano Pro).
  • Processar transações recorrentes cadastradas por você.
  • Autenticar sua sessão de forma segura via JWT.
  • Processar pagamentos da assinatura Pro via Stripe.
  • Enviar comunicações relacionadas ao serviço (atualizações, confirmações).

Não usamos seus dados para publicidade, perfilamento ou qualquer finalidade comercial além do próprio serviço.

4. Compartilhamento de dados

Não vendemos nem repassamos seus dados pessoais a terceiros. Utilizamos os seguintes provedores de serviço, todos com políticas de privacidade próprias e compliance com LGPD:

  • Stripe: processamento de pagamentos (Plano Pro). Seus dados de pagamento são gerenciados diretamente pelo Stripe.
  • Meta (WhatsApp Business API): canal de comunicação. Mensagens trafegam pela infraestrutura do WhatsApp com criptografia de ponta a ponta.
  • Provedor de IA (Plano Pro): textos e áudios são enviados para processamento de linguagem natural. Não são armazenados pelo provedor após o processamento.

Em casos de obrigação legal (ordem judicial, autoridade regulatória), podemos ser obrigados a divulgar dados. Notificaremos o usuário sempre que legalmente possível.

5. Armazenamento e segurança

Seus dados são armazenados em banco de dados PostgreSQL com as seguintes medidas de segurança:

  • Autenticação via JWT (JSON Web Token) com expiração automática.
  • Conexões criptografadas (TLS/SSL).
  • Monitoramento em tempo real dos sistemas.
  • Acesso restrito ao banco de dados por lista de IPs autorizados.
  • Backups regulares dos dados.

Nenhum sistema é 100% invulnerável. Em caso de incidente de segurança que afete seus dados, você será notificado via WhatsApp no menor prazo possível, conforme exigido pela LGPD.

6. Retenção de dados

  • Conta ativa: dados mantidos enquanto você utilizar o serviço.
  • Após cancelamento: dados mantidos por até 90 dias para possível reativação. Após esse prazo, são excluídos permanentemente.
  • Exclusão imediata: você pode solicitar a exclusão completa dos seus dados a qualquer momento pelo WhatsApp.
  • Áudios (Plano Pro): excluídos imediatamente após o processamento pela IA, sem armazenamento.

7. Seus direitos (LGPD)

Conforme a Lei Geral de Proteção de Dados (Lei 13.709/2018), você tem o direito de:

  • Acesso: solicitar uma cópia de todos os dados que temos sobre você.
  • Correção: atualizar dados incorretos ou desatualizados.
  • Exclusão: solicitar a exclusão de todos os seus dados pessoais.
  • Portabilidade: receber seus dados em formato estruturado (JSON ou Excel).
  • Revogação do consentimento: cancelar o uso do serviço a qualquer momento.
  • Informação: saber com quais terceiros seus dados foram compartilhados.

Para exercer qualquer um desses direitos, envie uma mensagem para o nosso WhatsApp: +55 47 8472-3085. Respondemos em até 5 dias úteis.

8. Cookies e rastreamento

O Boot Finance opera exclusivamente via WhatsApp. Não utilizamos cookies, pixels de rastreamento ou qualquer tecnologia de rastreamento em nosso serviço principal.

Esta página de política de privacidade não utiliza ferramentas de analytics ou rastreamento de visitantes.

9. Menores de idade

O Boot Finance é destinado a maiores de 18 anos. Não coletamos intencionalmente dados de menores. Se identificarmos uma conta de menor de idade, a conta será encerrada e os dados excluídos.

10. Alterações nesta política

Podemos atualizar esta política periodicamente. Em caso de alterações relevantes, você será notificado via WhatsApp com antecedência mínima de 10 dias. O uso continuado do serviço após as alterações representa aceite da nova política.
